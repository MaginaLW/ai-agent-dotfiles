# Skills Reports

Generated inventory, analysis, dedupe, and auto-merge reports live here.

Generated reports and their sidecars are local operational evidence and must not
be committed, even after a secret scan or content redaction. Filenames can also
identify a machine or import batch. This README is the only tracked file here.

Keep the original reports in place when removing them from Git tracking. Do not
delete or move evidence, rewrite history, or re-add sanitized copies as imports.
Record only reviewed, machine-independent facts in the existing task record; see
[the report storage rules](../../reports/README.md).

This rule supersedes the former permission to commit reports in this placeholder
and the archived import-workflow plans. Removing current tracking does not remove
data from earlier commits.
