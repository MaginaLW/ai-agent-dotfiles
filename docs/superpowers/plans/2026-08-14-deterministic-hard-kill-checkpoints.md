# Deterministic Hard-Kill Checkpoints Execution Plan

> **For agentic workers:** REQUIRED EXECUTION FLOW: Use `subagent-driven-development` to execute this plan task-by-task when subagents are available. If no subagent capability is available, execute inline with the same task checklist and review checkpoints.

**Goal:** Replace timing-dependent forward-mutation `FileSystemWatcher` sampling with deterministic, tests-only typed boundaries while keeping production transaction code free of test seams and preserving real production preimage and rollback execution.

**Approach:** Mirror only four narrow mutation bodies whose required boundary cannot be causally stopped from ordinary user-mode filesystem primitives: workspace create, parent create, directory replacement, and file replacement. Each sealed tests-only mirror calls the same production journal, SafeTree, lease, and native mutation surfaces and differs only by one mandatory typed invocation-context parameter plus allowlisted standalone `Invoke-SealedMutationReach` statements. That context is the sole child-side owner of a scalar-only coordinator and a separate native stage-root lease; no mirror or wrapper may obtain either through ambient or dynamic scope. A tests-only PowerShell reach wrapper performs the real held-journal read; the native stage-root lease owns atomically secured evidence-root creation, relative publication, sealed-final capture, and identity-relative cleanup, while the sealed C# coordinator owns only immutable selector data, the interlocked exact-match state machine, and the two-event `StageReady/Continue` handshake. Continue to execute the real production target/transaction-preimage chain, the existing source/header/source/intent oplock ladder, and the real rollback primitive. Treat a retained partial preimage as a direct crash-state/reconciliation fixture, not as proof of interrupting the production copy loop.

**Non-goals:** Do not modify `scripts/` to expose a checkpoint, callback, failpoint, provider, environment hook, or test parameter. Do not use a debugger, minifilter, command shadow, `ScriptBlock`, dynamic invocation, timing retry, or a directory child-create oplock. Do not claim that a synthetic partial-copy fixture intercepted the production copy implementation.
