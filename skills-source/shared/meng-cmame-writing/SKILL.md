# Meng-informed CMAME writing

从已读合著论文学习论证组织、公式解释、图表分工和比较口径，以原创英文表达。
语料支持的是可迁移的学术写法，不是作者个人独有语言的鉴定，也不是 CMAME 官方模板。

## 1. 先判断本次任务

读取用户最新要求和已有材料，采用以下模式；一次只完成所请求的范围。

| 模式 | 触发 | 应交付 |
| --- | --- | --- |
| PREPARE | 阅读、总结规律、准备、构思，或明确“先不写” | 文献/论点关系、章节职责、证据与图表任务、缺口；不生成论文正文 |
| DRAFT | 明确要求起草某节/全文 | 所需英文稿，附简短取证与待填项；有足够授权就执行 |
| POLISH | 提供或指定文本要求润色 | 修改文本、必要的改动理由、科学含义未决项；范围跟随用户要求 |

若明确要求先准备，不因材料齐全而自动进入 DRAFT/POLISH。
只在缺少决定性输入时提问；可独立完成的准备继续推进。
润色与写作本身不启动训练、补实验或改状态台账。

## 2. 按需加载

- 使用前读 [写作规律与适用条件](references/patterns.md)。这是方法依据。
- 需要引用、谈年代差异或确认归纳来源时读 [语料索引](references/corpus.md)。
  以索引中的版本和页码定位；不能声称摘要材料已读全文。
- 任务属于 PINN-tFORM 时读 [项目写作配置](references/pinntform-profile.md)，
  再从当前仓库入口定位相关实现/状态。其他项目不加载该配置。
- 投稿格式问题当次核对期刊官方作者指南；不要从已发表PDF推断字数、版式或文件要求。

## 3. 建立最小论证骨架

先从材料提取：研究问题、直接近邻方法、具体缺口、本文构造、证据、适用范围。
对每项候选贡献建立下列关系，数量由内容决定：

`具体困难 → 方法动作/数学对象 → 可观测变化 → 验证图表 → 有界结论`

模块名不自动等于创新。写作参考不替代查新；未核邻近全文时不宣称“首次”。
预设成功的稿件可按用户指定完成态组织；未知数值、排名、速度比、区间和图仍保持明确待填。
将该前提在工作稿/准备材料的适当位置说明一次，不反复把内部研究历史塞进正文。

## 4. 用规律组织内容

1. **引言逐层收窄**：工程/计算问题 → 与缺口有关的方法分类 → 仍未处理的具体困难 →
   本文处理方式。文献段落按解决什么组织，引用紧贴对应主张。
2. **公式服务于推理**：先说明对象、假设和变量空间；公式后定义新增符号、解释作用，
   再说明下一步使用哪些输出。长例行推导可入附录，关键新构造保留正文。
3. **图和算法各有职责**：框架图说明依赖，机制图解释变化，算法给输入/循环/终止/输出。
   按需选用，不强制三件齐全。
4. **结果按证据任务组织**：配置和参考口径 → 关键观测 → 机制解释 → 适用范围。
   算例递进、场景矩阵、模块消融都是选项，不固定五例或相同篇幅。
5. **结论回扣证据**：概括已验证的构造、最重要观察及覆盖范围；局限从剩余误差、
   假设或成本自然导出，不引入新数据或无条件优势。

摘要在论证骨架清楚后写：问题/缺口、具体构造、验证范围、主结果与意义。
不按参考文献原句换词，也不提供作者惯用原句拼接模板。

## 5. 润色的操作顺序

1. 建立原文保留清单：数学对象、公式、符号、失效方向、数值/单位、图表引用、
   比较分母、训练与评估来源、限定词和不确定度。
2. 先修段落论证：主题句是否清楚；证据能否支持评价；观察和解释是否分开。
3. 再修句子：让主语、动作、对象明确；删重复背景和空泛褒义；拆开承担多个任务的长句；
   用一致术语衔接，不为避免重复而替换关键数学名词。
4. 比较修改前后保留清单；校对方程/图表编号、缩写首定义、单位、有效位和参考版本。
5. 遇到科学矛盾，保留原始记录并指出具体问题；不得借润色暗改数值、方法或证据强度。

描述当前方法和方程通常用现在时，已执行试验用过去时；这是编辑建议，服从上下文，
不机械全篇改时态。直接、清楚比模仿句式重要。

## 6. 比较句的证据规则

每个精度/效率主张须能定位到比较对象、指标、参考、共同条件和覆盖范围。
没有同口径证据时只陈述已有观测，不补最优排名或因果结论。

- 场误差、响应误差、导数误差、可靠度指标误差、概率误差分别命名。
- 迭代数、函数调用数、梯度调用、wall time分别报告；子步骤收益不代替总成本收益。
- 最佳值、均值、离散程度分别判断；几何图相似不等于概率精度通过。
- 观测支持“与某机制一致”时，不自动升级为已证明因果或严格收敛。
- 成功场景不自动推出各指标同时最优；读过的论文也存在反例，见规律文件P7。

## 7. 完成交付

PREPARE交付可直接用于后续写作的关系表和任务，不附赠整段摘要/引言。
DRAFT/POLISH按用户指定的节、语言和文件形式交付，必要说明用用户语言。
只报告实际读取、修改和检查过的内容；论文事实与作者风格观察分开。
更新本skill时保留语料版本、页码与反例；新增全文后再扩展规律支持集合。
