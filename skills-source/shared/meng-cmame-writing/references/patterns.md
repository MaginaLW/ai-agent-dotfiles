# 写作规律、反例与迁移

本文件区分**观察**与**编辑规则**：观察来自[语料ID](corpus.md)中的具体段落/图表；
编辑规则是据此提出的做法，不冒充作者亲述。支持集合用于追溯，不表示对全体作品的频率估计。
以论证功能为单位学习，不模仿原句、不复刻预印本排版。

## P1 引言由方法分类收束到可计算的困难

**观察**：S21 pp1–2对照越界率与极值路线；P23 pp1–3从可靠度方法进入代理与PINN；
D22论文pp3–5聚焦内外循环；O24 pp4–5最终分出目标/约束协同与内层可靠度搜索；
T25 pp2–4由频/时域和确定/不确定走向时变建模及导数成本；G26 p4落到气泡误分类与初始样本成本。
支持集合 `{S21,P23,D22,O24,T25,G26}`。

**编辑规则**：每个综述段完成“这类方法做什么、与本文有关的限制、下一段为何必要”。
最后的困难应能与方法构造和验证任务相连。缺口限定到对象/假设/计算操作，避免泛称现有方法不好。

**例外**：E16引言已有FORM公式且另接工程材料问题；不能强制所有引言无公式。
M22是比较研究，缺口是统一比较不足，不必虚构新算法。

## P2 贡献、方法模块和验证相互对应

**观察**：D22摘要三策略→§3组件→§4.3累加消融；O24摘要分DO/RBDO构造→§§3–4→
每例两类问题；T25的时变不确定性与灵敏度难点对应§3模型/导数和§4场景研究。
支持集合 `{D22,O24,T25}`，这是直接证据较集中的三篇，不称九篇共同模板。

**编辑规则**：写贡献前建“困难—动作—产物—证据”关系。方法模块可贡献实现完整性，
不一定贡献新理论；基于既有模块的组合须说明新增关系，不能靠缩写命名制造创新。
有多模块改进时安排消融；方法目标若是建模而非逐模块提速，采用场景比较也合适。

## P3 先固定对象和基准，再解释改动

**观察**：S21、P23分背景与新构造；D22先RBDO/PMA/EO再提出算法；O24先DO/RBDO/Kriging；
F23从确定性到概率模型和敏度；T25先动态背景再时变稳健模型。
支持集合 `{S21,P23,D22,O24,F23,T25}`。

**编辑规则**：首次出现时固定变量空间、事件方向、假设和输出。把关键公式放在它所解决的问题之后；
随后解释新增符号和计算作用。数值稳定处理给理由、定义和适用条件。
不要在每节重新讲通用神经网络原理，也不要把不可省略的核心定义全部推到附录。

**例外**：E16把FORM放引言；D22的详细算例在附录；T25把混合导数推导留正文。
章节位置和篇幅随理解成本变化，没有统一公式数量。

## P4 机制图、流程图、算法和结果图承担不同任务

**观察**：D22论文p10框架/几何图后接算法；O24 pp10–11给两阶段示意和伪代码；
G26 pp5–6先画旧覆盖缺陷，pp7–8再给单/多模式和流程；T25 pp17–18用伪代码表，
pp22/24/33用对齐拓扑和收敛小图。支持集合 `{D22,O24,G26,T25}`。

**编辑规则**：机制图解释“改动为什么可能有效”；总流程表示依赖和重复调用；
算法框便于执行；结果图展示真实变化。图注说明对象、变化项、固定条件、符号与子图对应。
同组图固定坐标/视角/图例；不同量纲不为了整齐共享色标。

**例外**：不是每篇都有全部图型。期刊单/双栏、作者稿跨页表格及配色不构成个人固定习惯。
不要为凑图数量画重复流程，科研结果图不得用生成图代替计算数据。

## P5 算例按验证问题组织，数量和形式可变

**观察**：P23与O24各五例，S21三例，G26八例；E16一个梁加控制/物理参数族；
M22按六案例多指标比较；D22按总对比、消融、高维组织且把定义外置；
T25是三例中嵌套DTO/RTO/TDRTO×COV×权重×载荷时长矩阵。

**编辑规则**：先给每个例子的证据职责，再选“由简到繁”“同例参数矩阵”或“组件消融”。
算例开头交代模型、随机量、边界、响应/失效与配置；共同设置集中说明，局部差异就地给出。
五例成功可以是本文既定写作前提，但不是模仿作者所要求的数量。

**例外**：T25前两例有MCS表，三维例没有对应误差表；不能归纳为每例验证完全一致。
统一表头便于比较，不表示允许把未测列填成成功。

## P6 结果段从可定位观测走向机制解释

**观察**：E16 Table2/Fig.2分别看最终成本与振荡；O24 pp13–14把调用/误差表与样本分布联系；
G26 pp9–14表列Pf/调用/COV/误差并连接覆盖机制；T25把目标、拓扑形态、收敛和MCS分别展现。
支持集合 `{E16,O24,G26,T25}`。

**编辑规则**：一段先说最相关的观察，再指出图/表证据，最后解释与构造的关系及其范围。
不逐格抄表，也不让“表中可见结果很好”承担论证。没有消融/理论支持的解释保持适当限定。

可按内容需要包含以下语义单元，而不是固定句型：
`共同条件 + 指标差异 + 可定位证据 + 机制解释 + 适用范围`。
精度与成本方向不一致时拆成两句，保留权衡。

## P7 比较必须按列判断，不能学习笼统优势修辞

这是**反例驱动的编辑规则**，不是声称作者每篇已做到。

| 来源 | 具体反例/边界 | 写作动作 |
| --- | --- | --- |
| E16 Table2，印刷148 | 控制因子0.5时DCC迭代75<107，调用17153>11983。 | 不以迭代少推导函数调用少或wall time短。 |
| D22 Table3，论文23 | TC5最佳值与均值、SD、时间并非同向。 | 最佳值不代表稳定性或整体性能。 |
| M22 §3.3、§5 | 合并候选构成参考前沿，且不存在全指标赢家。 | 说明参考来源，限定案例/指标，不把排名当真值。 |
| F23 Table3，PDF13 | 分列FEA、优化器更新和完整迭代。 | 子步骤收益与总成本分开，比较基础写清。 |
| O24 Table4，PDF15 | U误差9.8341e-6低于OPM1.6254e-5，而OPM调用更少。 | 分别陈述精度和代价，不写逐指标全面最优。 |
| G26 Table4，PDF11 | DS调用数和误差均小于GOBSM。 | 不把反复出现的最高性能措辞升级为普遍结论。 |

P23 pp5–6还指出PINN训练可能比传统PDE求解慢。
本项目应分别记录场/响应/导数/概率误差和各阶段成本，不能把零参考监督调用写成零总计算成本。

## P8 结论回到构造、覆盖范围与剩余问题

**观察**：P23 p17谈训练振荡/成本；S21 p10谈离散与近似误差；G26 pp13–14承认边界附近仍有
未覆盖样本；T25 pp34–35把大规模成本接到降阶；O24 pp22–23把推广方向接到其他优化任务。
支持集合 `{P23,S21,G26,T25,O24}`。

**编辑规则**：结论不新增结果；概括本研究支持的认识，再说明剩余误差、计算代价或适用条件。
成功结果允许有适用边界，不要求把失败开发历史写成主线。

**例外**：E16/F23没有独立局限小节。是否专设Discussion/Limitations由内容和期刊要求决定。

## 跨时期比较：观察到什么，不能推断什么

| 样本组 | 观察到的组织选择 | 本项目可用之处 |
| --- | --- | --- |
| 2016 E16 | 短篇工程比较，公式进入引言，单模型参数族，重视迭代过程。 | 小范围机制研究也需明确指标和物理条件。 |
| 2021–2023 S21/D22/M22/P23/F23 | 局部近似、模块算法、多指标比较、PINN或拓扑模型分别形成不同主线。 | 选择与研究问题相配的结构，贡献和验证须对应。 |
| 2024–2026 O24/T25/G26 | 组合构造、导数推导或几何诊断获得专门篇幅，场景矩阵/多模式/高维扩展增加。 | 为核心难点分配篇幅，图表展示机制和覆盖，不只是最终误差。 |

这不是“作者越写越复杂”的定论：样本少，早期两人合著，部分跨期刊与版本，主题也不同。
固定的可以是论证纪律，变化的应是章节长度、算例数量和展示方式。

## 语言润色：采用功能，不复制习惯句

以下为本skill的编辑建议：

- 主题句点出本段问题/结论，随后给定义或证据；删除不增加信息的重复引导。
- 方法动作明确：哪一个量由哪个模型/公式计算、输入输出是什么。
- 同一对象保持同一术语；标准空间、原物理空间、切空间不得以修辞互换。
- 数学关系用准确动词，区分近似、构造、估计、观察与证明。
- 控制笼统评价词，用指定指标及范围承载精度/效率判断。
- 引文按技术主张放置；参考作者身份不构成其结论免检的理由。
- 逐项核对图号、表头和正文引用：M22 Table9候选标签、D22 Fig.7对象图注、
  T25章节预告均有可见不一致，不将此类缺陷带入新稿。

## 可执行交付骨架（不是正文模板）

准备时给四张紧凑关系表即可：
1. 问题/近邻/差异/引用待核；
2. 贡献候选/方法节/需证明什么；
3. 算例/指标/参考/图表/数据来源；
4. 可立即准备/数据待回填/下一次写作范围。

润色时先保留事实，再调整论证和语言；遇原文不受证据支持的“总是”“所有方法”“绝对安全”，
应收窄表述并单列原因，不替作者编造补证。
