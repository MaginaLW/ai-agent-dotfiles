# AI Agent Dotfiles

Local Windows dotfiles scaffold for Claude Code and Codex configuration plus shared skill sources.

This repository is intentionally conservative:

- `skills-source/` is the only hand-maintained skill source tree.
- `claude/skills/` and `codex/skills/` are generated by `scripts/build-skills.ps1` and ignored by Git.
- Real secrets, login state, auth files, SSH keys, local caches, and runtime history must never enter the repository.
- Scripts are PowerShell 7+ only and must use explicit `-RepoRoot` and, when relevant, `-HomeRoot` parameters.
- Stage 1/2 only provides local scaffolding, checks, build output, and fake-home testing. Real sync is intentionally not active yet.

## Current Stage

Implemented for phase 1 and phase 2:

- Repository skeleton and safe ignore rules.
- Central whitelist manifest at `manifests/whitelist.psd1`.
- Secret scanning wrapper with gitleaks first and a custom fallback scanner.
- Skill build script from `skills-source/` to local generated targets.
- Hook inspection script.
- Placeholders for sync, backup, hook activation, and Claude MCP application.

Not implemented in this stage:

- Real push or pull sync.
- Real writes to `$HOME/.claude`, `$HOME/.codex`, or `$HOME/.agents/skills`.
- Hook activation.
- GitHub remote creation or push.
